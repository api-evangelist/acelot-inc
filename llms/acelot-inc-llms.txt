# Acelot, Inc.

> Clinical-stage biopharmaceutical company in South San Francisco, California, developing
> first-in-class small-molecule therapies for neurodegenerative disease. Lead candidate ACE-2223
> targets misfolded, aggregated TDP-43 to restore its healthy form and function — pathology central
> to ALS and frontotemporal lobar degeneration (FTLD). Discovery is run on Resolute, Acelot's
> internal AI-driven computational-chemistry drug-discovery platform.

**There is no Acelot API.** Acelot publishes no public API, developer portal, API reference, SDK,
CLI, webhook surface, MCP server, agent card or machine-readable specification. Probed 2026-09-06:
`/openapi.json`, `/openapi.yaml`, `/swagger.json`, `/api-docs`, `/graphql`, `/mcp`, `/llms.txt` and
the RFC 8615 `/.well-known/*` set all returned 404 on both `acelot.com` and `www.acelot.com`. The
Resolute platform is described by the company as employed in-house; it is not offered as a hosted
service or programmable product. If you are an agent looking for an Acelot endpoint to call, there
is not one — contact info@acelot.com instead.
